This repository contains my SQL Server practice questions and solutions, organized topic-wise from basic to advanced levels. It is designed to strengthen my SQL knowledge, improve query-writing skills, and develop problem-solving abilities for database management, data analytics, and data science.

I will continuously add new questions and solutions as I progress in learning Microsoft SQL Server and T-SQL.

How to Use This Repository

1. Clone or download this repository.
2. Navigate to the folder for the topic you want to practice.
3. Open the relevant ".sql" file in SQL Server Management Studio.
4. Execute the queries in a compatible SQL Server environment.
5. Try solving each question independently before checking the solution.
